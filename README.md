# 30-Day Backend API Challenge

This repository contains a collection of small, production-style backend APIs built using **FastAPI**.  
Each API focuses on a different concept — calculations, external API calls, CRUD operations, and data processing — and includes **unit tests** using `pytest` and FastAPI’s `TestClient`.



## 🚀 How to Run

.\venv\Scripts\activate
uvicorn todo_api.main:app --reload
pytest -v
